# AI slop 黑名单（自查用）

命中任一条都要修。主要来源：@dingyi https://x.com/dingyi/status/2115790005423734818 ，并合并 @ZaynHao、@ianneo_ai、@Xian0063 的条目。

## 字体与文字
- [ ] 使用 Instrument Serif / Space Grotesk / Bricolage Grotesque
- [ ] 滥用等宽字体（非代码/数字处）
- [ ] 到处都是标签（badge/tag）和斜体
- [ ] 全大写小标题；标题上方小眉标（eyebrow）；章节编号；代码式面包屑
- [ ] hero 字号大得离谱
- [ ] 字号超过 4 种，或最小字号 < 12px
- [ ] 中文页面 font-family 中文在前 / 无 sans-serif 兜底

## 颜色
- [ ] 紫色或紫蓝渐变；渐变按钮
- [ ] 彩色图标；一张卡片一种颜色
- [ ] 界面外壳用了多种颜色（应只用灰阶 + 1 强调色）
- [ ] 半透明叠色堆叠

## 线条、圆角、阴影
- [ ] 边框粗细不统一；该 0.5px 的用了 1px
- [ ] 分割线、带边框容器过多
- [ ] 多层阴影
- [ ] 嵌套处圆角不同心（不满足 r = R − p）
- [ ] 卡片左边缘彩色竖线
- [ ] 卡片套卡片

## 布局与交互
- [ ] 全部居中排版
- [ ] 标题前装饰 emoji/图标
- [ ] 下拉菜单按钮多余的下拉小图标
- [ ] 滚动动效过多、过渡生硬；进场用 ease-in
- [ ] 图表细节过度

## 文案
- [ ] 中圆点 `·` 当分隔符
- [ ] 解释性描述文字画蛇添足
- [ ] 过度口语化或自造词
- [ ] 正文塞 emoji、堆无用文字
- [ ] 编造数据/社会证明（如 "10,000+ 满意客户"）

## 量化阈值
| 指标 | 上限 |
|---|---|
| 字号种类 | 4（推荐 3） |
| 最小字号 | 12px |
| 强调色（不含灰阶） | 1（品牌色总计 3–5） |
| 边框宽度种类 | 1（0.5px） |
| 阴影种类 | 0–1 |
| 进场动画时长 | ~250ms ease-out |
